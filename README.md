# Manual de Epidemiología

Manual de Epidemiología para alumnos de grados en Ciencias de la Salud.

Libro escrito con [Quarto](https://quarto.org) a partir del tutorial de
[Epidemiología](https://aprendeconalf.es/docencia/estadistica/tutoriales/epidemiologia/)
de [aprendeconalf.es](https://aprendeconalf.es).

## Contenidos

1. Introducción a la Epidemiología
2. Probabilidad y odds
3. Medidas de frecuencia de una enfermedad (prevalencia e incidencia)
4. Medidas de asociación (riesgo relativo y odds ratio)
5. Tests diagnósticos (sensibilidad, especificidad y valores predictivos)
6. La curva ROC

## Compilación

```sh
quarto render        # Genera el libro en HTML, PDF y EPUB en la carpeta docs/
quarto preview       # Previsualización con recarga automática
```
